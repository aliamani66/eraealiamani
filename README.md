این مخزن شامل اسلایدهای ۱۶:۹ باکیفیت، متن کامل سناریو و گفتار استیج، ارائه‌ی قابل اجرا با کلیکر، موتور ماژولار تولید خودکار (Presentation Builder Engine)، و اسکیل اختصاصی Antigravity برای توسعه و نگهداری آسان پروژه است.

## 🛠️ معماری موتور ساخت خودکار (Builder Engine)

ارائه به صورت کاملاً اعلامی (Declarative) مدیریت می‌شود تا با اضافه شدن اسلاید یا تغییر عکس‌ها، هیچ لینکی خراب نشود.

### فایل‌های اصلی:
- **`slides_config.json`**: مانیفست کامل اسلایدها، فهرست ایستگاه‌ها (`stations`)، متن‌های روی اسلاید (`text_overlays`) و یادداشت‌های سخنران.
- **`build_presentation.py`**: موتور پردازشگر پایتون برای ساخت، اعتبارسنجی و کامپایل فایل‌های پاورپوینت.
- **`.agents/skills/techtalk-presentation-builder/SKILL.md`**: اسکیل هوش مصنوعی برای مدیریت و افزودن اسلایدها.

## ➕ راهنمای افزودن یا تغییر اسلایدها

برای افزودن یک اسلاید جدید یا اصلاح اسلایدهای فعلی، نیازی به تغییر کد پایتون نیست:

### ۱. قرار دادن فایل تصویر
تصویر ۱۶:۹ جدید را داخل پوشه `slides/` قرار دهید (مثلاً `slides/new_station.jpg`).

### ۲. تعریف اسلاید در `slides_config.json`
اسلاید جدید را در موقعیت دلخواه در آرایه `"slides"` اضافه کنید:

```json
{
  "id": "slide_station_new",
  "file": "new_station.jpg",
  "type": "station",
  "title": "اسلاید جدید — عنوان ایستگاه",
  "station": "cloud",
  "notes": "📌 راهنمای استیج:\nنکات گفتار..."
}
```

### ۳. ثبت ایستگاه در نوار پیشرفت (در صورت نیاز)
اگر اسلاید یک ایستگاه است، ایستگاه را در آرایه‌ی `"stations"` (به ترتیب نمایش از راست به چپ) اضافه کنید و همان شناسه را در `"station"` اسلاید بگذارید:

```json
{ "id": "cloud", "year": "۱۴۰۱", "title": "معماری کلود" }
```

شناسه‌ی ناشناخته خطای validate می‌دهد و ایستگاهی که اسلایدی ندارد هشدار می‌گیرد.

### ۴. اجرای کامپایل ارائه
دستور زیر را در ترمینال اجرا کنید:

```powershell
python build_presentation.py
```

موتور به صورت خودکار:
- صحت وجود فایل‌های تصاویر را بررسی می‌کند.
- نوار پیشرفت اسلایدهای ایستگاه را بر اساس `stations` می‌سازد.
- ترنزیشن Fade را اعمال می‌کند (`"transition": "none"` برای مرحله‌ی بعدیِ همان اسلاید).
- اگر اسلایدی کلید `"video"` داشته باشد و فایل در `slides/` موجود باشد، ویدئو را تمام‌صفحه جاسازی می‌کند؛ وگرنه متن جایگزین می‌ماند و فقط هشدار می‌دهد.
- خروجی را فقط در `TechTalk_Dinosaurs_Survival.pptx` ذخیره می‌کند. **این فایل، ارائه‌ی نهایی است.**
- اگر این فایل در پاورپوینت باز باشد، پیام خطای واضح می‌دهد، با کد خروج غیرصفر تمام می‌شود و فایل را تغییر نمی‌دهد. پاورپوینت را ببندید و دوباره اجرا کنید.

## ⚡ دستورات کاربردی خط فرمان (CLI)

- **ساخت مجدد ارائه:**
  ```powershell
  python build_presentation.py
  ```

- **اعتبارسنجی کانفیگ و عکس‌ها بدون ساخت فایل:**
  ```powershell
  python build_presentation.py --validate
  ```

- **خروجی گرفتن با نام سفارشی:**
  ```powershell
  python build_presentation.py --output "TechTalk_Final_Custom.pptx"
  ```

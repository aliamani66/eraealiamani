# ارائه تعاملی تک‌تاک: دایناسورهای دنیای تک و مهارتِ بقا
> **TechTalk: "Dinosaurs of Tech & The Survival Skill" — Interactive PowerPoint Presentation & Modular Engine**

پروژه ارائه چندرسانه‌ای و تعاملی در خصوص سیر تحول ۱۶ ساله مهندسی نرم‌افزار، عملیات (DevOps/SRE)، معماری کلود و مواجهه با پدیده هوش مصنوعی (AI).

این مخزن شامل اسلایدهای ۱۶:۹ باکیفیت، متن کامل سناریو و گفتار استیج، ارائه تعاملی کلیک‌پذیر (Interactive Clickable Deck)، موتور ماژولار تولید خودکار (Presentation Builder Engine)، و اسکیل اختصاصی Antigravity برای توسعه و نگهداری آسان پروژه است.

---

## 🗺️ ساختار تعاملی ارائه (Interactive Highway Architecture)

در این ارائه ۱۳ اسلایدی، چیدمان به صورت مینیمال و بدون تداخل با سربرگ تصاویر طراحی شده است:

1. **اسلاید ۱ (کاور رسمی رویداد):** راهروی آینده‌نگر دیتاسنتر و خطوط نوری فیبر نوری (`cover_option1_datacenter.jpg`).
2. **اسلاید ۲ (پرده اول - استعاره انقراض و بقا):** دایناسور تایتان سرورها و رک‌های صلب زیر شهاب‌سنگ تحول، و پستانداران چابک سایبرنتیک روی خطوط ارتباطی (`slide2_option_cyber_dinosaur.jpg`).
3. **اسلاید ۳ (پرده اول - دوقلوهای ترس):** تصویر مهندس نرم‌افزار میان دو ستون هولوگرافیک خطا در پروداکشن و عصر هوش مصنوعی (`slide2_option1_twins_of_fear.jpg`).
4. **اسلاید ۴ (بزرگراه ۱۶ ساله مسیر شغلی):** نقشه راه نوری سایبرنتیک با ۷ ایستگاه سال‌های شمسی (۱۳۸۸ تا ۱۴۰۳+).
   - **کلیک‌پذیری کامل (Hotspots):** با بردن موس روی هر کدام از ۷ ایستگاه در حالت ارائه (Present Mode / F5)، نشانگر موس به دست کلیک‌پذیر تبدیل شده و با کلیک، فوراً به اسلاید همان ایستگاه منتقل می‌شوید.
   - **دکمه میانبر پرده پایانی:** آیکون ظریف `[ ☄️ ]` در بالا برای پرش مستقیم به بخش پایانی.
5. **اسلایدهای ۵ تا ۱۱ (ایستگاه‌های مسیر شغلی):**
   - **ایستگاه ۱ (۱۳۸۸):** دژ برنامه‌نویسی ناب جاوا و جهش جسورانه به عملیات.
   - **ایستگاه ۲ (۱۳۹۵):** وب‌لاجیک انترپرایز و ماژول احراز هویت اختصاصی (Authenticator).
   - **ایستگاه ۳ (۱۳۹۶):** فاجعه حلقه For و ضرورت اتوماسیون با Jenkins.
   - **ایستگاه ۴ (۱۳۹۷):** گذر از جزیره‌های لاگ و متمرکزسازی در ELK Stack.
   - **ایستگاه ۵ (۱۳۹۸):** تیم R&D Ops و فرهنگ طلایی «بساز، تحویل بده و رها کن».
   - **ایستگاه ۶ (۱۴۰۰):** نقطه اوج — ساعت ۰۶:۰۰ صبح بانک و مهاجرت بیگ‌بنگ به کوبرنتیز.
   - **ایستگاه ۷ (۱۴۰۳+):** پلتفرم خودکارسازی هوشمند ISR و دستیاران هوش مصنوعی.
   - **ناوبری مینیمال و پاکیزه (Icon-Only):**
     - هیچ بج یا بنری روی هدر تصاویر قرار ندارد (هدر اختصاصی هر عکس کاملاً تمیز و خوانا است).
     - آیکون کلیک‌پذیر `[ 🗺️ ]` در گوشه بالا برای بازگشت فوری به بزرگراه.
     - آیکون‌های ظریف `[ ▶ ]` و `[ ◀ ]` در گوشه‌های پایین برای ورق زدن روان.
6. **اسلاید ۱۲ (شهاب‌سنگ هوش مصنوعی):** تقابل دایناسورهای صلب و پستانداران کوچک تطبیق‌پذیر (`slide9.jpg`).
7. **اسلاید ۱۳ (پیام طلایی بقا):** شکستن پوسته Legacy Core، پرواز کالبد کوانتومی به سوی آینده: «پوسته خود را بشکافید، تغییر کنید، پوست بیندازید و زنده بمانید» (`slide2_option3_evolution_shedding.jpg`).

## 🛠️ معماری موتور ساخت خودکار (Builder Engine)

ارائه به صورت کاملاً اعلامی (Declarative) مدیریت می‌شود تا با اضافه شدن اسلاید یا تغییر عکس‌ها، هیچ لینکی خراب نشود.

### فایل‌های اصلی:
- **`slides_config.json`**: مانیفست کامل اسلایدها، تنظیمات بزرگراه، نقاط کلیک‌پذیر (Hotspots) و متن‌های استیج.
- **`build_presentation.py`**: موتور پردازشگر پایتون برای ساخت، اعتبارسنجی و کامپایل فایل‌های پاورپوینت.
- **`.agents/skills/techtalk-presentation-builder/SKILL.md`**: اسکیل هوش مصنوعی برای مدیریت و افزودن اسلایدها.

## ➕ راهنمای افزودن یا تغییر اسلایدها

برای افزودن یک اسلاید جدید یا اصلاح اسلایدهای فعلی، نیازی به تغییر کد پایتون نیست:

### ۱. قرار دادن فایل تصویر
تصویر ۱۶:۹ جدید را داخل پوشه `slides/` قرار دهید (مثلاً `slides/new_station.jpg`).

### ۲. تعریف اسلاید در `slides_config.json`
اسلاید جدید را در موقعیت دلخواه در آرایه `"slides"` اضافه کنید:

```json
{
  "id": "slide_station_new",
  "file": "new_station.jpg",
  "type": "station",
  "title": "اسلاید جدید — عنوان ایستگاه",
  "badge": "📍 ایستگاه جدید (۱۴۰۱): معماری کلود و میکروسرویس",
  "back_to_roadmap": true,
  "nav_buttons": true,
  "next_text": "ایستگاه بعدی ◀",
  "notes": "📌 راهنمای استیج:\nنکات گفتار..."
}
```

### ۳. اتصال ایستگاه جدید در بزرگراه (در صورت نیاز)
در بخش `"roadmap_settings" -> "hotspots"`، هاس‌پات آن را تعریف کنید:

```json
{
  "id": "station_new",
  "name": "ایستگاه جدید",
  "target_slide_id": "slide_station_new",
  "box_px": [700, 180, 200, 400],
  "ref_image_size": [1376, 768]
}
```

### ۴. اجرای کامپایل ارائه
دستور زیر را در ترمینال اجرا کنید:

```powershell
python build_presentation.py
```

موتور به صورت خودکار:
- صحت وجود فایل‌های تصاویر را بررسی می‌کند.
- تمام لینک‌های بازگشت به بزرگراه و دکمه‌های قبلی/بعدی را بر اساس ترتیب جدید بازتنظیم می‌کند.
- ترنزیشن‌های سینمایی Fade را اعمال می‌کند.
- خروجی را در `TechTalk_Dinosaurs_Survival_Interactive.pptx` و `TechTalk_Dinosaurs_Survival.pptx` ذخیره می‌نماید.

## ⚡ دستورات کاربردی خط فرمان (CLI)

- **ساخت مجدد ارائه:**
  ```powershell
  python build_presentation.py
  ```

- **اعتبارسنجی کانفیگ و عکس‌ها بدون ساخت فایل:**
  ```powershell
  python build_presentation.py --validate
  ```

- **خروجی گرفتن با نام سفارشی:**
  ```powershell
  python build_presentation.py --output "TechTalk_Final_Custom.pptx"
  ```
